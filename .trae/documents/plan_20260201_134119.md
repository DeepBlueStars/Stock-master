# 实现计划

## 1. 后端修改

### 1.1 修改Users实体类
- 在`Users.java`中添加`email`和`cash`属性
- 添加对应的getter和setter方法

### 1.2 新增用户信息接口
- 在`ConfigController.java`中添加两个新接口：
  - `GET /config/userInfo`：获取用户个人信息（用户名、邮箱、现金）
  - `POST /config/updateCash`：修改用户当前的现金

### 1.3 修改StockService.java
- 修改`sell`方法，当用户卖出股票时，计算卖出的金额，加到当前用户的现金额中
- 修改`buy`方法，添加对买入方式的判断，如果是现金则扣除用户当前的现金

### 1.4 修改assetCategoryPosition接口
- 修改`StockService.java`中的`getAssetCategoryPosition`方法，现金类的positionAmount从users集合中的cash属性获取

## 2. 前端修改

### 2.1 新增配置页面
- 创建`src/components/Config.vue`页面组件
- 在页面中展示用户名、邮箱、现金信息
- 添加修改现金的功能

### 2.2 修改路由配置
- 在`src/router/index.js`中添加配置页面的路由

### 2.3 修改App.vue
- 确保菜单中的配置项点击后跳转到新的配置页面

### 2.4 修改Dashboard.vue
- 在买入股票弹窗中新增“买入方式”下拉框
- 显示用户当前的现金额
- 默认选择“现金”方式
- 调用“确认买入”按钮时，将买入方式作为参数传到后端接口

## 3. 实现步骤

1. 首先修改后端代码：
   - 更新Users实体类
   - 新增用户信息接口
   - 修改StockService中的相关方法
   - 修改assetCategoryPosition接口

2. 然后修改前端代码：
   - 创建配置页面组件
   - 更新路由配置
   - 修改App.vue菜单跳转
   - 修改Dashboard.vue买入弹窗

3. 测试所有功能是否正常工作

## 4. 技术要点

- 后端使用Spring Boot和MongoDB进行数据操作
- 前端使用Vue 3和Element Plus构建界面
- 确保接口调用方式与现有代码风格保持一致
- 注意数据类型的处理，特别是现金金额的计算

# 配置资产前端页面设计与开发方案

## 1. 页面结构设计

### 1.1 整体布局
- 采用 Element Plus 的 `el-container` 布局容器
- 顶部为页面标题和操作按钮区域
- 左侧为资产类型选择/管理区域
- 中间为资产比例调整控制区域
- 右侧为配置预览/结果展示区域
- 底部为保存/重置功能按钮

### 1.2 响应式设计
- 大屏幕：三栏布局（资产类型 + 比例调整 + 配置预览）
- 中屏幕：两栏布局（资产类型+比例调整 + 配置预览）
- 小屏幕：单栏布局，各模块垂直排列

## 2. 组件划分

### 2.1 主组件
- `AssetConfig.vue`：主页面组件，整合所有子组件

### 2.2 子组件
- `RatioAdjuster.vue`：比例调整组件
- `ConfigPreview.vue`：配置预览组件
- `AssetChart.vue`：资产配置图表展示组件

## 3. 数据结构设计

### 3.1 资产配置数据结构
```javascript
{
  id: String,           // 配置方案ID
  name: String,         // 配置方案名称
  description: String,  // 配置方案描述
  assets: [             // 资产列表
    {
      id: String,       // 资产ID
      name: String,     // 资产名称
      type: String,     // 资产类型（stock/bond/gold/cash）
      ratio: Number,    // 配置比例（0-100）
      color: String,    // 资产颜色标识
      icon: String      // 资产图标
    }
  ],
  createdAt: Date,      // 创建时间
  updatedAt: Date       // 更新时间
}
```

### 3.2 状态管理
- 使用 Vue 3 的 Composition API 和 `reactive` 进行状态管理
- 主要状态包括：
  - 当前配置方案
  - 可用资产类型列表
  - 配置比例总和
  - 操作状态（保存中、加载中）

## 4. 功能实现

### 4.1 资产类型管理
- 支持预定义资产类型（股票、债券、黄金、现金）
- 支持自定义资产类型的添加、编辑和删除
- 资产类型包含名称、类型、颜色和图标

### 4.2 比例调整功能
- 使用 Element Plus 的 `el-slider` 组件实现比例调整
- 同时提供 `el-input-number` 组件进行精确输入
- 实时计算并显示各类资产的配置比例总和
- 实现比例调整限制机制，确保总比例为100%
  - 当调整某一资产比例时，自动调整其他资产比例
  - 提供智能调整算法，优先调整比例较大的资产

### 4.3 配置预览功能
- 使用 ECharts 实现资产配置饼图展示
- 实时更新饼图数据，反映最新配置比例
- 显示各类资产的详细信息（名称、比例、颜色）
- 提供配置比例的文字描述

### 4.4 配置保存/加载功能
- 支持将当前配置保存为方案
- 支持从已保存方案中加载配置
- 支持配置方案的重命名和删除
- 使用 localStorage 进行本地存储（后续可扩展为后端存储）

## 5. 交互设计

### 5.1 实时反馈
- 比例调整时，实时更新饼图和比例总和
- 提供操作成功/失败的消息提示（`el-message`）
- 按钮状态根据操作状态动态变化

### 5.2 限制机制
- 确保总比例始终为100%
- 单个资产比例范围限制在0-100%之间
- 至少保留一种资产类型

### 5.3 操作流程
1. 用户选择/添加资产类型
2. 通过滑块或输入框调整资产比例
3. 实时查看配置预览
4. 保存配置方案或重置配置
5. 可加载已保存的配置方案

- 滑块拖动时的实时反馈

### 7.2 关键功能实现

#### 7.2.1 比例调整算法
```javascript
// 当某一资产比例变化时，自动调整其他资产比例
const adjustAssetRatios = (changedIndex, newRatio) => {
  // 计算比例变化量
  const diff = newRatio - assets[changedIndex].ratio;
  
  // 更新当前资产比例
  assets[changedIndex].ratio = newRatio;
  
  // 计算剩余资产需要调整的比例
  const remainingAssets = assets.filter((_, index) => index !== changedIndex);
  const totalRemainingRatio = remainingAssets.reduce((sum, asset) => sum + asset.ratio, 0);
  
  // 按比例分配变化量
  remainingAssets.forEach(asset => {
    if (totalRemainingRatio > 0) {
      const adjustDiff = (asset.ratio / totalRemainingRatio) * diff;
      asset.ratio = Math.max(0, Math.min(100, asset.ratio - adjustDiff));
    }
  });
};
```

#### 7.2.2 本地存储实现
```javascript
// 保存配置方案
const saveConfig = (config) => {
  const savedConfigs = JSON.parse(localStorage.getItem('assetConfigs') || '[]');
  savedConfigs.push({
    ...config,
    id: Date.now().toString(),
    createdAt: new Date().toISOString(),
    updatedAt: new Date().toISOString()
  });
  localStorage.setItem('assetConfigs', JSON.stringify(savedConfigs));
};

// 加载配置方案
const loadConfig = (configId) => {
  const savedConfigs = JSON.parse(localStorage.getItem('assetConfigs') || '[]');
  return savedConfigs.find(config => config.id === configId);
};
```

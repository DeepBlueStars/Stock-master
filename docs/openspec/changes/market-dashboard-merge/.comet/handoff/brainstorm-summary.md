# Brainstorm Summary

- Change: market-dashboard-merge
- Date: 2026-10-28

## 确认的技术方案

采用「新建单一组合页面 + 旧路由重定向 + 删除旧组件」方案：

- 新建 `StockAI-Console/src/components/MarketOverview.vue`，作为唯一市场页面，路由 `/market`。
- 页面从上到下：头部（标题、交易日、刷新）→ 摘要指标条 → 市场温度（左 8/24）/ 选股榜单（右 16/24）→ 热点方向双栏（行业 12/24、概念 12/24）→ 历史记录折叠面板。
- 数据层使用 `Promise.allSettled` 并行请求四个现有接口，每个区块独立维护 loading/error/data，单接口失败不影响其他区块。
- 路由层新增 `/market`，`/regime` 与 `/screener` 使用 `redirect` 跳到 `/market`；`App.vue` 导航收敛为单一「市场」入口。
- 删除 `MarketRegime.vue`、`StockScreener.vue`，避免双份实现。
- 不新增后端接口、不新增前端依赖、不引入图表库。

（用户已明确要求全流程自动审批，仅在 verify 阶段停止等待验证，因此本确认点按用户预授权记录为已确认。）

## 关键取舍与风险

- 取舍：双栏而非简单上下拼接，可让 1440px 宽屏首屏同时看到「市场状态 + 候选股」；代价是选股表格可读宽度压缩，通过 `size="small"`、固定关键列宽和 `show-overflow-tooltip` 缓解。
- 取舍：删除旧组件而非复用，避免两套实现漂移；旧路径用重定向保证兼容。
- 风险：页面信息密度提高后小屏拥挤 → `el-col` 的 `xs/md/lg` 断点堆叠，表格设置 `max-height` 与横向滚动。
- 风险：后端某接口无数据或失败导致区块空白 → 每块独立空态/错误文案，摘要条缺值显示 `-`。
- 风险：深色模式下自定义浅色背景失效 → 只用 CSS 变量与 `.dark` 局部覆盖，不硬编码主题色背景。

## 测试策略

- 项目无前端测试框架且本次不引入新依赖，因此不在本 change 内新增单元测试。
- 构建验证：在 `StockAI-Console` 执行 `npm run build`，确保 Vue 模板、路由与组件引用全部可编译。
- 人工验证：访问 `/market`、`/regime`、`/screener`，确认统一页面展示与重定向；按 1440/1024/768 三档宽度检查排版与无横向滚动；切换深色模式检查可读性；模拟接口失败/空数据检查分区降级。
